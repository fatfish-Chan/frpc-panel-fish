# 大肥鱼 frpc 面板 · Electron 桌面版

给 [frp](https://github.com/fatedier/frp) 做的桌面小面板：每条映射一张卡片，开关一拨就自动写配置并重载 frpc。
不用 Python、不用浏览器，后端是 Node 标准库写的。

## 现在就能跑

```bash
npm install
npm start
```

国内下载 Electron 慢就加镜像：

```bash
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm install
```

最小化启动（只留托盘）：`npm run start:min`

## 打包成 exe

```bash
npm run build
```

产物在 `dist/大肥鱼frpc面板.exe`，单文件绿色版，双击即用，不用装。

## 界面

- 没有系统标题栏，顶部一条自绘的：拖它就能移窗口，右边两个键是「最小化 / 收进托盘」。
- 窗口大小固定，拖边不能缩放；桌面小的机器会按屏幕自动缩。
- 卡片默认一行横着排，规则多了直接横向滚动，鼠标滚轮也能滑。
- 右上「⛶ 横滑」切成方块铺开，一眼看全；再点一下「↔ 横滑」回去。

## 用起来

- 窗口右上关闭 → 收到托盘，不中断 frpc。
- 托盘图标左键：显示/隐藏；右键：显示面板、最小化到托盘、打开 frp 目录、打开数据目录、退出。
- 界面里所有改动（开关、增删改规则、设置里的服务端地址和 token）都会立刻写配置并重启 frpc。
- 「⚙ 设置」里能改服务端地址、端口、token、frpc 路径、配置路径、格式、日志。

## frp 文件放哪

- 开发/源码跑：放本目录下 `frp/`（`frpc.exe` + `frpc.toml` 或 `frpc.ini`）。
- 打包后的 exe：放**exe 同目录**的 `frp/` 文件夹。
- 找不到可以在「⚙ 设置」里手填路径。

## 目录

```
main.js        窗口 / 托盘 / 单实例 / 自绘标题栏
preload.js     给页面暴露最小化的窗口控制
server.js      内置 HTTP 后端（规则读写、配置生成、重启 frpc）
renderer/      前端页面和大肥鱼图标
scripts/       打包后瘦身钩子
frp/           你的 frpc.exe 和配置
data/          规则与设置（自动生成）
```

## 端口

固定 127.0.0.1:8899，只监听本机。端口被占时会直接连上已经在跑的那个。
